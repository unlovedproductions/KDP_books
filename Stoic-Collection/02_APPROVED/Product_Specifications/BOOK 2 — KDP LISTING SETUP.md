## Description (HTML allowed in KDP; plain version below)

**Stoic Shadow Work Journal** is a guided workbook in *The Stoic Collection* for people who avoid hard truths, repeat the same patterns, and want a method—not slogans.

Using the permanent practice spine **SEE → SORT → OWN → CHOOSE → REVIEW**, you will:

- Map avoidance and self-deception without turning the page into therapy cosplay  
- Separate facts from added judgments under real pressure  
- Drill signature practices you can reuse after the book ends  
- Log what actually changed—not what you wish you believed  

This is Book 2. Book 1 (*Stoic Foundations*) installs the method in depth. You can start here; the Method Primer supplies what you need to work.
